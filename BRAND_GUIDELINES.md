# Brand Guidelines — The Modern Statistical Atelier

## 1. Positioning
- **Umbrella Brand**: DataSense Studio (configurable via `src/config/brand/brand.json`).
- **Central Positioning**: *Serious statistical tools, made approachable.*
- **Supporting Idea**: *Five focused laboratories. One connected way to understand data.*
- **Lifecycle**: `Prepare → Explore → Visualize → Investigate → Infer → Forecast`.

## 2. Hub Extensions to Canonical DESIGN.md
The canonical `DESIGN.md` defines the core tokens shared across the application workbenches (`#F6F4EE` warm archival paper, `#0F6E56` phosphor emerald, `#D9381E` vermilion, `#141619` deep charcoal ink). The central hub preserves `DESIGN.md` untouched and introduces marketing-specific scale extensions:
- **Expressive Editorial Hero Scale**: Fluid `clamp(2.65rem, 4.8vw, 4.5rem)` serif display headline (`Instrument Serif` / `Georgia`).
- **Dark Instrument Showcase Contrast**: Deep slate-black (`#0D1014` / `#151921`) with phosphor emerald (`#34D399`) accents for the QuartetLab feature panel and the closing call to action.
